## Estado actual

Plataforma de scouting genérica. **No pertenece a ningún club todavía.**

**Why:** La sección "Plantel" está vacía porque no hay club asociado. Los datos de Transfermarkt pueden estar incompletos para algunos jugadores.

**How to apply:**
- No asumir que hay un club dueño de la plataforma
- El "Plantel" está vacío por diseño hasta que se asocie a un club
- Los datos de valor de mercado, agente, etc. pueden faltar para algunos jugadores

### Origen
Plataforma originalmente de Doble G Sports (agencia), adaptada a formato genérico.

### Cambios realizados:
1. "Scouting Interno" → "Plantel"
2. Dashboard eliminado
3. "GG Score" → "Scoring datos"
4. Logos de agencia → Placeholders
5. Referencias "Doble G" → Genérico

### Mantiene:
- Branding verde (#22C55E), estilo Apple
- Funcionalidades: Dispersión, Detector, Comparación, Formaciones, PDFs
- Sistema de multiplicadores por liga en scoring
